go-awards

Программа для создания наградной документации: быстро, бесплатно, на любой платформе.

🏆 Что делает программа?

Программа помогает создавать наградную документацию. Написана на языке Go, использована графическая библиотека Fyne для создания интерфейса. Обеспечена кроссплатформенность, поэтому попробовать проект может каждый абсолютно бесплатно.

⭐ Чем она лучше аналогов?

В go-awards уже встроены все инструменты, которые потребуются для создания качественных документов. Есть возможность переносить шаблоны, то есть можно скидывать их своим коллегам и друзьям! Удобные инструменты позволяют делать генерацию автоматизированной: макросы подстановки и склонения ФИО; макросы, зависящие от пола участника; иерархия текстовых блоков; встроенная утилита diff, которая позволяет сравнивать результат и эталонный документ и многое другое!

👥 Для кого эта программа?

Данный продукт подойдет для организаторов различных мероприятий. Студентам для ознакомления с работой с pdf и с версткой документов на typst.
